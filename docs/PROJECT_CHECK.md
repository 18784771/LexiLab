# LexiLab 项目 CHECK 验收标准

本文件给出当前极简学习交互的验收清单。详细结果和真实数据见 `docs/ACCEPTANCE_REPORT.md`。

## 主界面

- [ ] `lexi` 在 TTY 中只显示“开始今日学习 / 设置 / 退出”三个入口。
- [ ] 默认高亮“开始今日学习”；直接按 Enter 返回 `study`。
- [ ] 主界面显示今日新词完成/目标、今日复习完成/目标、学习时间、总体进度。
- [ ] 主菜单不出现单词复习、新词学习、统计、词库、快速筛选、听力、阅读、写作独立按钮。

## 设置

- [ ] 设置包含学习计划、学习统计、词库管理、专项训练、AI 配置、语音配置、界面与特效、数据备份与恢复、返回。
- [ ] 学习计划可修改每日新词、每日时间、new/old/interleaved 顺序、自适应新词、延迟回忆、错词强化、专项训练开关。
- [ ] 设置修改保存到 TOML，且不重置今日已完成计数。
- [ ] 统计、词库、关系查询、专项训练仍可正常调用。
- [ ] 所有菜单可用方向键、Enter、数字键、Esc 完成。

## 学习流程

- [ ] 默认 `plan_order=new_first`：新词初学 → 到期复习 → 延迟回忆 → 可选错词强化 → 总结。
- [ ] 可配置 `old_first` 与 `interleaved`。
- [ ] 到期积压且 `adaptive_new_words=true` 时自动减少/暂停新词。
- [ ] 学习计划不再生成强制 VERIFY 项。
- [ ] 退出后重新“开始今日学习”能恢复未完成项。
- [ ] 跨天重新计算到期与今日计数。

## 方向键

- [ ] `→` 记录 Easy 并立即下一张，不展示释义。
- [ ] `←` 记录 Again，展示释义/搭配/例句，按 Enter 下一词。
- [ ] `↑` 展示答案；再按 `←` 记录 Again，按 `→` 记录 Hard。
- [ ] 看到答案后才想起来不会被记录为 Hard。
- [ ] 每张卡只写入一次正式评分；重复/长按方向键不会重复。
- [ ] 新词初学 `→`/`↑→` 只写一次 review_log，并跳过对应延迟回忆项。
- [ ] 文本输入状态方向键只移动光标，不触发评分。
- [ ] `Good` 未从 FSRS/文本反馈/高级评分中删除。

## 保持项

- [ ] WordNet + RapidFuzz 关系库和 smart 新词排序保持正常。
- [ ] FSRS 到期队列和已有卡片状态不被关系/排序逻辑修改。
- [ ] 实时打字粒子、抖动、脉冲、Combo、TTE 保留。
- [ ] 无 AI 环境可完整学习。
- [ ] 从其他工作目录调用 `lexi` 仍使用配置指定的统一 `learning.db`。
- [ ] `pytest` 全量通过，`ruff check src tests scripts` 通过。
