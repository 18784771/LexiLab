# LexiLab 新词学习排序设计

## 1. 原来的问题

原 `Planner` 通过：

```sql
ORDER BY m.rank, w.word_key
```

获取新词。`rank` 来自词书导入顺序，CET6 原始 JSONL 基本按字母整理，因此默认新词序列是词典检索顺序：

```text
abandon → ability → able → abnormal → ...
```

这不是学习顺序。它没有回答：

- 哪些词在实际语言中更常用？
- 哪些词与用户已经掌握的词有关？
- 同一批新词是否在拼写/语义上互相干扰？
- 用户是否实际混淆过某两个词？
- 当前时间预算和到期复习量是否允许引入新词？

## 2. 四种策略

| 策略 | 用途 | 默认 |
|---|---|---|
| `smart` | 词频 + 已学关联 + 干扰控制 + 混淆优先 | 是 |
| `frequency` | 纯词频，便于复现实验 | 否 |
| `related` | 优先已学词的 WordNet 关联 | 否 |
| `alphabetical` | 词库浏览/检索/对照 | 否 |

`alphabetical` 不再作为默认值，只作为显式选择；相同分数时保留源词书稳定顺序，不重新按字母排序。

## 3. 评分函数

```text
score(w) =
    frequency_weight   × frequency_score(w)
  + relatedness_weight × relatedness_score(w)
  + confusion_priority × confusion_bonus(w)
  - interference_penalty × batch_interference(w, selected)
```

### 3.1 词频

ECDICT 的 `frq` 是词频排名，**数值越小越常用**（已验证：`able=385`、`mitigate=8991`）。系统优先使用：

1. `frq > 0`；
2. `bnc > 0`；
3. 词库 `frequency > 0`；
4. 词书 `rank` 的弱降级；
5. 中性分。

对数尺度避免最常用的几十个功能词完全垄断所有批次，同时保留“高频优先”的方向。`collins` 星级和 `oxford` 核心词作为小加成。

### 3.2 已学关联

关系引擎为已学词查找 WordNet 边：

- 同义 1.0；
- 派生 0.9；
- 反义 0.7；
- 上下位 0.6；
- 语义相似 0.5；
- 语义相关 0.4；
- 形近 0.45。

候选词与已学词的权重和归一化后作为 `relatedness_score`。例如已学 `predict` 时，`prediction` 的派生边会提高其优先级；已学 `mitigate` 时，`lessen`/`relieve` 等 WordNet 关联词获得加分。

### 3.3 个人混淆

`confusion_pairs` 中出现的候选词获得小幅加成（按次数，最多 3 次封顶）。这不是“越难越先学”，而是承认用户已经实际暴露过该词形差异，适合尽早纠正。

### 3.4 记忆干扰

批次选择不是一次性排序，而是迭代选择：

- 每个候选与已选词计算 Damerau-Levenshtein 相似度；
- 达到阈值的候选被降权（至少 0.35）；
- 选完后做一次轻量调度：如果相邻两个词仍高度相似，尝试插入一个非相似词；
- 同义词集中不直接等同于“相似度排序”，只在专项辨析模式中主动提高。

这个策略避免：

```text
adapt → adopt → adept → ...
```

在用户尚未建立第一个词的基本记忆时连续轰炸。

## 4. 可解释性

每个被选词包含理由，例如：

```text
排序示例 prediction:
- ECDICT frq 排名 1613
- 已学习相关词 predict（派生）
- Collins 3 星
```

理由写入：

- `SessionPlan.notes`（只展示第一个示例，避免刷屏）；
- `session_items.payload_json.recommendation`（完整列表，便于调试/后续 UI 详情）。

## 5. 与 FSRS 的关系

必须保持：

1. 到期卡先于新词；
2. 关系引擎不写 `cards`、`review_logs`；
3. 新词仍使用 `interleave_gap` 插入主动回忆；
4. 关系/词频只影响新词候选顺序，不影响到期队列排序；
5. 词库重导入和关系重建不改变既有 FSRS 状态。

代码层由 `Planner.build` 先选 `selected_due`，再调用 `SmartNewWordOrderer.choose`，因此到期优先级不可能被关系分数覆盖。

## 6. 学习科学依据

### 6.1 有研究支持的学习机制

- **频率与覆盖**：高频词在真实语料中覆盖更多文本，优先学习可提高即时可用性（Nation, 2006; Laufer & Ravenhorst-Kalovski, 2010）。
- **精细加工/语义网络**：把新词与已学词建立语义连接，有利于提取路径（Craik & Lockhart, 1972; Barcroft, 2002 的语义 elaboration 讨论）。
- **提取练习**：主动回忆优于重复阅读（Roediger & Karpicke, 2006）。
- **间隔与交错**：分散学习和交错练习通常优于集中重复（Cepeda et al., 2006; Rohrer & Taylor, 2007）。
- **干扰/相似性**：高度相似的材料可能产生竞争性提取，需要间隔、对比和独立测试（Anderson & Reder, 1999 关于 fan effect 的讨论；具体到二语词汇仍需实验）。
- **错误驱动学习**：真实错误可提供纠正反馈，但错误本身不是学习成功的证据。

### 6.2 工程策略

以下不是被证明的“最优参数”，而是基于上述机制的可解释工程选择：

- 词频用对数尺度，避免功能词垄断；
- 关联词加分，但同批相似词降权；
- 个人真实混淆优先；
- 保留 `frequency`/`alphabetical` 作为可复现对照；
- 关系分数不写入 FSRS。

### 6.3 需要实验验证的假设

- LexiLab 用户群体中，`smart` 是否比 `frequency` 带来更好的 7 天延迟回忆；
- 形近词干扰惩罚的阈值（0.80）是否适合不同水平用户；
- 关联词优先是否会导致语义网络过度集中；
- 个人混淆加成的合适上限。

**不能**用本次静态排序对照证明学习效果。真正的效果验证需要随机分组、固定学习时间、匹配初始词汇难度，并比较 7/30 天延迟回忆；本报告不伪造该结果。

## 7. 可复现实验建议

1. 招募同一水平学习者，随机分为 A/B/C/D 四组；
2. 固定每日学习时长、初始未知词数量和复习窗口；
3. 记录新词覆盖、7 天延迟回忆、错误率、混淆对变化；
4. 预先注册主要指标，避免事后挑选有利结果；
5. 报告置信区间和退出率。
