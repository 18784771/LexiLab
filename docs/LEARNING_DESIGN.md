# LexiLab 学习策略设计

## 1. 理论依据与落地方式

| 原则 | 在 LexiLab 中的具体实现 |
|---|---|
| Active Recall | 复习先展示问题，用户独立回忆后才显示答案；中译英必须输入 |
| Spaced Repetition | 由 Py-FSRS 计算 due date；不自行编写或调参替代算法 |
| Retrieval Practice | 新词不在展示答案后立刻判定“已记住”，而是在插入其他词后再次提取 |
| Semantic Elaboration | 展示词性、核心义、搭配、例句；详细同义词/词根通过 `e` 按需查看 |
| Corrective Feedback | 客观题即时判定并给出差异；开放题由 AI 批改，错误回流到训练队列 |
| Four Strands | 词汇（复习/新词）、语境输入（阅读/听力）、输出（造句/写作）、流利度（限时连续作答） |

## 2. 记忆调度：只使用 FSRS

- 引擎：`fsrs`（Py-FSRS 官方包）。
- 评分：`Again=1`、`Hard=2`、`Good=3`、`Easy=4`。
- `Hard` 表示成功回忆但很困难，不是答错。完全忘记、看答案后才想起、未完成回忆均记 `Again`。
- 默认目标保持率 0.90，可配置；它是初始建议，不是对所有学习者最优的证明。
- 界面展示的 `Retrievability` 是 FSRS 的预测值，不等于真实测试正确率；真实正确率单独统计。

### 2.1 两张独立卡片

| 卡片 | 方向 | 目的 |
|---|---|---|
| Recognition | 英文 → 中文 | 词义识别 |
| Recall | 中文释义 + 语境 → 英文 | 主动提取 |

- 两张卡分别保存 FSRS 状态。认识一个词不代表能主动写出它。
- Recall 卡默认延迟 `recall_delay_days` 天启用，避免新词第一天产生双倍复习压力。
- 同一单词只建立这两张 FSRS 卡片；拼写、听力、语境、写作能力通过训练记录评估，不额外制造六张 FSRS 卡。

### 2.2 事务一致性

每次评分在同一事务内：

1. 用 FSRS 计算新卡片状态；
2. 更新 `cards`；
3. 插入 `review_logs`（评分、耗时、复习时状态、间隔）。

任何一步失败则回滚，不出现“日志已写但卡片未更新”。

## 3. 新词学习流程

1. **尝试识别**：只显示单词，问“认识 / 不确定 / 不认识”。此步骤不写入记忆成功。
2. **核心信息**：音标、主要词性与中文释义、一个搭配、一个例句。默认克制展示；`e` 查看完整释义、短语、同义词、同根词。
3. **间隔插入**：把该词的主动回忆安排在至少 `interleave_gap` 个其他学习项之后，避免即时重复造成的熟悉感。
4. **主动回忆**：显示英文，用户回忆中文，按 Enter 显示答案，再按 1–4 自评。
5. **首次 FSRS 记录**：仅以这次真实回忆的评分为准。若选择“认识”但回忆失败，仍记 `Again`。
6. **Recall 卡延迟启用**：到期后自动解除暂停，进入中译英训练。

初次浏览不等于成功记忆；程序不会因为用户看了答案就给出 `Good`。

## 4. 快速筛选

`lexi screen` 用于已有基础的词汇：

- **已认识**：不创建永久“掌握”状态，而是登记一次延迟抽查（默认 1、3、7、14、30、90 天）。
- **不确定 / 不认识**：立即建立 Recall 延迟、Recognition 到期的卡片，进入正常学习。
- 抽查失败：立即创建/恢复卡片并按 `Again` 记录；抽查成功：安排下一次更长间隔的抽查。

因此“已认识”是一个可被证据推翻的假设，而不是不可撤销的结论。

## 5. 每日调度规则

`Planner` 的确定性规则（按顺序）：

1. 先取到期卡片，按“近 14 天错误次数降序、due 升序”排序。
2. 到期量超过 `pause_new_when_due_over` 时，新词数为 0。
3. 否则新词数 = min(每日上限 − 今日已学, 剩余时间预算允许量)。
4. 时间预算：复习按 `review_seconds`、新词按 `new_word_seconds` 估算；`--minutes` 覆盖每日配置。
5. 每个会话最多 `max_reviews_per_session` 张到期卡，避免无限长队列。
6. 近期错误词在训练目标词选择中加权。
7. 同一材料不会在同一天被无条件重复生成；缓存命中直接复用。
8. 阅读、听力、写作按最近使用日期轮换推荐，但用户可显式选择。
9. 用户可以只用 `lexi learn` / `lexi review`，完全不进入 AI 训练。

以上是工程化的优先级规则，不是“最优学习科学参数”。所有阈值都可配置。

## 6. 短时强化与长期记忆的区分

- 评分 `Again` 后，本会话可在间隔 2–3 题后再次出现，但这次只记为 `training_logs`（强化练习），不会新增一条 FSRS 复习成功记录。
- 同一张卡在同一会话内不会因为反复出现而获得多次长期记忆奖励。
- 跳过（`s`）不产生评分，只记录跳过事件；卡片仍然到期，下次继续。

## 7. 能力维度

| 能力 | 证据来源 | 未评估时 |
|---|---|---|
| Recognition | recognition 卡复习日志 | 未评估 |
| Recall | recall 卡复习日志 + 中译英训练 | 未评估 |
| Spelling | 拼写训练日志 | 未评估 |
| Listening | 听写/听音辨义日志 | 未评估 |
| Context | 语境填空、阅读作答 | 未评估 |
| Production | 造句/翻译/写作批改 | 未评估 |

统计接口不会把缺少记录的能力显示为 0 分，而是显示“未评估”或“数据不足”。

## 8. 延迟回忆指标

- 7 天/30 天延迟回忆正确率仅使用真实复习日志：本次复习与上次复习的实际间隔 ≥ 7/30 天，且评分 ≥ Good。
- 样本少于 5 次显示“数据不足”。
- 不使用 FSRS 预测概率冒充真实延迟测试结果。

## 9. AI 在学习闭环中的位置

AI 只负责生成材料与批改开放答案；它不决定卡片何时复习，不修改 FSRS 字段，不直接写数据库。

- 阅读：5–10 个目标词，150–250 词，2–3 道理解题；生成后做词形覆盖率校验。
- 听力：句子/篇章 TTS，默认隐藏原文；记录播放和重播次数，但不把重播当作学习成功。
- 写作：造句 → 句子翻译 → 段落写作；批改区分“真正错误 / 可接受表达 / 风格建议”。
- 错误回流：`word_errors` 记录搭配、词义、拼写等错误，后续 Planner/Training 优先选择这些词。

## 10. 明确不做的承诺

- 不声称某个掌握度分数是真实记忆概率。
- 不声称默认参数适合所有学习者。
- 不声称合成语音等同于真实交流环境。
- 不声称启发式批改（Mock）等同于真实 AI 批改。

## 11. 能力分级下的学习路径

`Planner` 只安排 Level 0 的记忆任务（复习、新词、筛选抽查、错词强化），因此任何可选模块缺失都不会中断学习流程。词汇阶段结束后，界面按当前能力提供后续训练：

| 可用能力 | 词汇阶段后的默认建议 |
|---|---|
| 无 AI、无语音 | 拼写训练 → 语境填空 → 总结 |
| 无 AI、有语音 | 拼写 → 单词听写/听音辨义/本地句子听写 → 总结 |
| 有 AI、有语音 | 词汇专项 → 阅读/听力/写作 → 纠错反馈 → 总结 |

训练入口动态生成；不可用功能不显示。AI 请求失败时提供本地拼写/语境训练或跳过，不把失败当成学习失败。已有缓存材料可通过 `lexi materials` 或主界面 `[9]` 离线查看；听力缓存音频可直接重播，不需要重新请求 AI 或重新合成。

AI 关闭不会删除历史材料、错误记录、写作批改、统计或 FSRS 状态；重新启用后可继续使用。
