# LexiLab 学习策略设计

## 1. 理论依据与落地方式

| 原则 | 在 LexiLab 中的具体实现 |
|---|---|
| Active Recall | 复习先展示问题，用户独立回忆后才显示答案；中译英必须输入 |
| Spaced Repetition | 由 Py-FSRS 计算 due date；不自行编写或调参替代算法 |
| Retrieval Practice | 新词不在展示答案后立刻判定“已记住”，而是在插入其他词后再次提取 |
| Semantic Elaboration | 展示词性、核心义、搭配、例句；详细同义词/词根按需展开 |
| Corrective Feedback | 客观题即时判定并给出差异；开放题由 AI 批改，错误回流到训练队列 |
| Four Strands | 词汇（复习/新词）、语境输入（阅读/听力）、输出（造句/写作）、流利度（限时连续作答） |

## 2. 记忆调度：只使用 FSRS

- 引擎：`fsrs`（Py-FSRS 官方包）。
- 评分：`Again=1`、`Hard=2`、`Good=3`、`Easy=4`。
- `Hard` 表示成功回忆但很困难，不是答错。完全忘记、看答案后才想起、未完成回忆均记 `Again`。
- 默认目标保持率 0.90，可配置；它是初始建议，不是对所有学习者最优的证明。
- 界面展示的 `Retrievability` 是 FSRS 的预测值，不等于真实测试正确率；真实正确率单独统计。

### 2.1 两张独立卡片

| 卡片 | 方向 | 目的 |
|---|---|---|
| Recognition | 英文 → 中文 | 词义识别 |
| Recall | 中文释义 + 语境 → 英文 | 主动提取 |

- 两张卡分别保存 FSRS 状态。认识一个词不代表能主动写出它。
- Recall 卡默认延迟 `recall_delay_days` 天启用，避免新词第一天产生双倍复习压力。
- 同一单词只建立这两张 FSRS 卡片；拼写、听力、语境、写作能力通过训练记录评估，不额外制造六张 FSRS 卡。

### 2.2 事务一致性

每次评分在同一事务内：

1. 用 FSRS 计算新卡片状态；
2. 更新 `cards`；
3. 插入 `review_logs`（评分、耗时、复习时状态、间隔）。

任何一步失败则回滚，不出现“日志已写但卡片未更新”。

### 2.3 方向键界面与 FSRS 语义

- 问题状态 → `Right`：记录 `Easy`；不展示答案，立即下一张。
- 问题状态 → `Left`：记录 `Again`；展示答案，按 Enter 后下一张。
- 问题状态 → `Up`：先核对答案；再选 `Left` 记 `Again`，选 `Right` 记 `Hard`。
- `Hard` 只表示“独立回忆成功但困难”；看到答案后才想起来仍记录 `Again`。
- `Good` 机制保留在 FSRS 层，文本训练或高级评分仍可使用。
- 一次学习事件只产生一条正式复习日志；初次浏览答案不算成功回忆。

### 2.4 特效与连击不参与记忆调度

Textual Power Mode 的粒子、抖动、脉冲和 Combo 属于纯表现层：

- 特效引擎不读取或写入 `cards`、`review_logs`、`training_logs`。
- Combo 只在“未使用提示且自动判定正确”的输入题中增加；使用提示、发音提示、跳过、
  答错均清零。
- Combo 不改变 FSRS 评分、不增加 `Good/Easy` 建议、不影响下次 due date。
- 动画使用 Textual timer/worker 异步执行，不阻塞下一题；关闭特效后学习路径完全不变。
- 提示状态会写入训练日志的 `hinted` 字段，用于统计与连击判断，但不伪造记忆成功。

## 3. 新词学习流程

1. **尝试识别**：只显示单词，问“认识 / 不确定 / 不认识”。此步骤不写入记忆成功。
2. **核心信息**：音标、主要词性与中文释义、一个搭配、一个例句。默认克制展示；完整释义、短语、同义词、同根词按需展开。
3. **间隔插入**：把该词的主动回忆安排在至少 `interleave_gap` 个其他学习项之后，避免即时重复造成的熟悉感。
4. **主动回忆**：显示英文和音标，用户先在心里回忆中文，然后用方向键判断：`←` 不记得、`↑` 不太确定、`→` 容易；`↑` 核对后可再选 `←`（Again）或 `→`（Hard）。
5. **首次 FSRS 记录**：仅以这次真实回忆的评分为准。若选择“认识”但回忆失败，仍记 `Again`。
6. **Recall 卡延迟启用**：到期后自动解除暂停，进入中译英训练。

初次浏览不等于成功记忆；程序不会因为用户看了答案就给出 `Good`。

## 4. 快速筛选的历史数据

快速筛选不再作为独立学习入口或主菜单功能。已有 `screening` 数据仍保留，不删除、不覆盖；`screening_known_keys` 仍可避免重复把已登记的词加入新词队列。方向键学习本身即可快速处理已认识词汇，不需要单独的筛选仪式。

## 4.1 每日自动学习流程

默认每日流程：

```text
新词初次方向键判断
      ↓
到期旧词复习（FSRS）
      ↓
新词延迟主动回忆
      ↓
可选错词强化
      ↓
总结
```

顺序由 `plan_order` 决定：`new_first`（默认）、`old_first`、`interleaved`。到期积压超过阈值时，`adaptive_new_words` 自动减少或暂停新词，保证到期复习优先得到时间。所有阶段自动衔接，用户不需要在每个阶段重新选择任务。

## 5. 每日调度规则

`Planner` 的确定性规则（按顺序）：

1. 取到期卡片，按“近 14 天错误次数降序、due 升序”排序；默认 `plan_order=new_first` 时新词初学排在到期复习之前，但延迟回忆仍在复习之后。
2. 到期积压超过 `pause_new_when_due_over` 且 `adaptive_new_words=true` 时，新词数为 0。
3. 否则新词数 = min(每日目标 − 今日已学, 剩余时间预算允许量)。
4. 时间预算：复习按 `review_seconds`、新词按 `new_word_seconds` 估算；`--minutes` 覆盖每日配置。
5. 每个会话最多 `max_reviews_per_session` 张到期卡，避免无限长队列。
6. 近期错误词在训练目标词选择中加权。
7. 同一材料不会在同一天被无条件重复生成；缓存命中直接复用。
8. 阅读、听力、写作按最近使用日期轮换推荐，但用户可显式选择。
9. 用户可以只用 `lexi learn` / `lexi review`，完全不进入 AI 训练。

以上是工程化的优先级规则，不是“最优学习科学参数”。所有阈值都可配置。

### 5.1 新词智能排序（默认）

新增词不再按字母顺序扫描。`new_word_order` 默认 `smart`，`Planner` 只对“未学习且未在筛选抽查中”的词评分：

1. **ECDICT 词频**：`frq` 越小越常用；缺失时回退 `bnc`、词库 `frequency`，再回退词书顺序。
2. **已学词关联**：WordNet 同义、派生、反义、上下位、相似/相关关系；已学词有边连接到候选词时加分。
3. **个人混淆**：真实“目标词 → 另一个真实单词”的替换记录获得额外优先级。
4. **记忆干扰惩罚**：本轮已选词与候选词 Damerau-Levenshtein 相似度达到阈值时降权，并在批次尾部尝试插入非相似词。
5. **时间预算/每日上限**：仍由原有 `Planner` 规则约束，不因排序改变到期复习优先级。

用户可显式选择 `frequency`、`related` 或 `alphabetical`。`alphabetical` 仅用于浏览/检索或实验对照；`lexi learn` 的默认值不是字母顺序。详细依据和限制见 `VOCABULARY_RELATION_DESIGN.md` 与 `LEARNING_ORDER_DESIGN.md`。

排序分数是工程策略，不是已经证明的“最优学习模型”。它不修改 FSRS 参数、卡片状态或到期时间。

## 6. 短时强化与长期记忆的区分

- 评分 `Again` 后，本会话可在间隔 2–3 题后再次出现，但这次只记为 `training_logs`（强化练习），不会新增一条 FSRS 复习成功记录。
- 同一张卡在同一会话内不会因为反复出现而获得多次长期记忆奖励。
- 跳过（`s`）不产生评分，只记录跳过事件；卡片仍然到期，下次继续。

## 7. 能力维度

| 能力 | 证据来源 | 未评估时 |
|---|---|---|
| Recognition | recognition 卡复习日志 | 未评估 |
| Recall | recall 卡复习日志 + 中译英训练 | 未评估 |
| Spelling | 拼写训练日志 | 未评估 |
| Listening | 听写/听音辨义日志 | 未评估 |
| Context | 语境填空、阅读作答 | 未评估 |
| Production | 造句/翻译/写作批改 | 未评估 |

统计接口不会把缺少记录的能力显示为 0 分，而是显示“未评估”或“数据不足”。

## 8. 延迟回忆指标

- 7 天/30 天延迟回忆正确率仅使用真实复习日志：本次复习与上次复习的实际间隔 ≥ 7/30 天，且评分 ≥ Good。
- 样本少于 5 次显示“数据不足”。
- 不使用 FSRS 预测概率冒充真实延迟测试结果。

## 9. AI 在学习闭环中的位置

AI 只负责生成材料与批改开放答案；它不决定卡片何时复习，不修改 FSRS 字段，不直接写数据库。

- 阅读：5–10 个目标词，150–250 词，2–3 道理解题；生成后做词形覆盖率校验。
- 听力：句子/篇章 TTS，默认隐藏原文；记录播放和重播次数，但不把重播当作学习成功。
- 写作：造句 → 句子翻译 → 段落写作；批改区分“真正错误 / 可接受表达 / 风格建议”。
- 错误回流：`word_errors` 记录搭配、词义、拼写等错误，后续 Planner/Training 优先选择这些词。

## 10. 明确不做的承诺

- 不声称某个掌握度分数是真实记忆概率。
- 不声称默认参数适合所有学习者。
- 不声称合成语音等同于真实交流环境。
- 不声称启发式批改（Mock）等同于真实 AI 批改。
- 不把特效、Combo 或界面反馈当作记忆强度的证据。

## 11. 能力分级下的学习路径

`Planner` 只安排 Level 0 的记忆任务（复习、新词、筛选抽查、错词强化），因此任何可选模块缺失都不会中断学习流程。词汇阶段结束后，界面按当前能力提供后续训练：

| 可用能力 | 词汇阶段后的默认建议 |
|---|---|
| 无 AI、无语音 | 拼写训练 → 近义词/形近词辨析 → 语境填空 → 总结 |
| 无 AI、有语音 | 拼写 → 单词听写/听音辨义/本地句子听写 → 总结 |
| 有 AI、有语音 | 词汇专项 → 阅读/听力/写作 → 纠错反馈 → 总结 |

训练入口动态生成；不可用功能不显示。AI 请求失败时提供本地拼写/语境训练或跳过，不把失败当成学习失败。已有缓存材料可通过 `lexi materials` 或主界面 `[9]` 离线查看；听力缓存音频可直接重播，不需要重新请求 AI 或重新合成。

AI 关闭不会删除历史材料、错误记录、写作批改、统计或 FSRS 状态；重新启用后可继续使用。
