# LexiLab 交互设计

## 1. 设计目标

每天使用的工具，首屏到开始学习最多一次按键；一道题最多一次按键进入答案、一次按键评分。所有操作都有明确的当前状态提示。

## 2. 输入状态机

```
单键快捷状态 ──Enter(作答)──▶ 文本输入状态 ──提交──▶ 结果反馈状态
      │                                              │
      └──────── q / Ctrl+C / Esc ────────────────────┘
```

- **单键快捷状态**：读取一个字符，不回车。`p/h/e/s/q/1-4/Enter` 生效。
- **文本输入状态**：使用行输入（`input()` / prompt_toolkit）。此状态下 `p`、`q`、`s` 只是普通字母，不触发快捷键。
- **结果反馈状态**：只接受 Enter 继续、`o` 覆盖评分、`q` 退出等明确按键；不把输入内容当作命令。

非 TTY（管道、CI）时：单键状态降级为逐行读取；行输入保持原样。无法交互的命令给出明确错误而不是挂起。

## 3. 统一快捷键

| 键 | 功能 |
|---|---|
| `Enter` | 显示答案 / 提交 / 进入下一步（界面必须标注当前含义） |
| `1`–`4` | Again / Hard / Good / Easy |
| `p` | 播放发音 |
| `h` | 提示 |
| `e` | 查看详细词义 |
| `s` | 跳过（不产生评分） |
| `q` | 保存并退出 |
| `Esc` | 返回（文本输入状态由行编辑器处理） |

## 4. 主界面

```
╭──────────────────────────────────────────────╮
│                  LexiLab                     │
│       Vocabulary-driven English Learning     │
├──────────────────────────────────────────────┤
│ 待复习：42    今日新词：10    生词：23        │
│ 已学习：1286  今日学习：12 min                │
├──────────────────────────────────────────────┤
│ [Enter] 开始今日学习                          │
│ [1] 单词复习      [2] 新词学习                │
│ [3] 听力训练      [4] 阅读训练                │
│ [5] 写作训练      [6] 学习统计                │

```

数字均为真实数据库查询结果。窄终端自动退化为垂直列表，不截断关键信息。

## 5. 复习界面

正面：

```
REVIEW                         12 / 42

                mitigate

请回忆这个单词的含义

[Enter] 显示答案   [p] 发音   [s] 跳过   [q] 退出
```

背面：

```
                mitigate  /ˈmɪtɪɡeɪt/

v. 缓解；减轻

mitigate the risk
降低风险

[1] 忘记  [2] 困难  [3] 正常  [4] 简单
[e] 详细词义   [p] 发音
```

英译中默认主动回忆 + 自评；中译英优先输入。

## 6. 中译英界面

```
RECALL                         08 / 20

缓解；减轻（动词）

We need to ______ the risk.

[Enter] 作答   [h] 提示   [p] 发音   [s] 跳过   [q] 退出

Your answer: mitigete

Correct answer: mitigate
拼写错误：第 5 个字母 a 被误写为 e

[Enter] 继续   [o] 修改评分
```

- 判定顺序：精确匹配 → 规范化匹配 → 合法词形 → 拼写近似。
- 拼写近似视为错误，但给出字符级诊断；评分建议 `Again`，用户可覆盖。
- 同义表达无法自动判定时，展示参考答案并允许用户自行判定（`y` 正确 / `n` 错误）。

## 7. 新词界面

```
NEW                            03 / 10

                mitigate

你认识这个单词吗？

[1] 认识   [2] 不确定   [3] 不认识   [q] 退出
```

展示核心信息后，该词被放入至少 3 个其他学习项之后，再要求主动回忆。`e` 随时展开完整释义、短语、同近义词、同根词。

## 8. 听力与写作

- 听力默认隐藏原文；`p` 播放、`r` 重播、`h` 提示、`s` 跳过。提交或放弃后才显示原文。
- 写作支持多行输入，以单独一行 `.` 或空行结束，界面明确提示。
- 批改结果按“错误 / 可接受 / 建议”分开显示，不把风格差异称为错误。

## 9. 终端兼容

| 场景 | 处理 |
|---|---|
| Windows Terminal / PowerShell | `msvcrt` 单键读取；UTF-8 输出 |
| Linux / WSL | `tty.setcbreak` 单键读取；恢复终端设置 |
| 窄终端 | 宽度 < 60 时使用紧凑布局；不画宽边框 |
| 不支持颜色 | 尊重 `NO_COLOR`、`--no-color`、非 TTY |
| 中文宽度 | 使用 Rich 的显示宽度计算，不手工按字节 |
| Ctrl+C | 捕获 `KeyboardInterrupt`，当前未提交题不记录，已提交记录保留，打印恢复提示 |
| Ctrl+D / EOF | 视为安全退出 |
| 异常退出 | 每题即时提交；重新启动可恢复 |
| 非交互 | 打印状态或明确错误，不阻塞等待输入 |

## 10. 减少操作成本的具体规则

- 主界面 Enter 直接开始今日学习，不需要重新配置。
- 评分只需一个数字键，不再确认。
- 复习背面与评分同屏，显示答案后无需再按 Enter。
- 跳过不弹二次确认。
- 退出只在有未完成会话时提示一次“下次可恢复”，不阻断退出。
- AI 不可用时不弹出错误风暴：首次提示一次，后续自动降级为本地功能。

## 11. 动态菜单与能力状态

主界面只展示当前可执行的任务：

| 条件 | 菜单变化 |
|---|---|
| AI `disabled/unconfigured/unavailable` | 隐藏 `[4] AI 阅读`、`[5] AI 写作` |
| AI `ready/error` | 显示 AI 入口；`error` 时允许重试 |
| 语音或播放器不可用 | 隐藏 `[3] 听音辨义/听写` 和所有 `[p] 发音` 提示 |
| 存在本地缓存材料 | 显示 `[9] 本地材料` |
| 始终 | 显示基础学习、统计、词库、筛选、`[c] 配置`、`[q]` |

数字键语义保持不变，隐藏某项时不重新分配其他数字键。可选模块缺失不会在菜单上产生警告条；`lexi doctor` 才展示详细状态。直接执行未启用的 AI 命令时，只输出：

```
AI 阅读模块尚未启用。

如需使用，请执行：
  lexi config ai
```

不输出 Python 异常堆栈。

## 12. 可选模块配置入口

```bash
lexi config          # 查看当前配置与能力
lexi config ai       # 启用/禁用、provider、model、base_url、密钥环境变量名
lexi config audio    # 启用/禁用、provider、voice、rate、player
lexi doctor          # 详细检测
```

密钥只通过环境变量读取；配置界面只显示变量名，不读取或打印密钥值。
